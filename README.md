# AI Radar

AI Radar — невеликий каталог нових AI-сайтів, створений за допомогою
публічного FreeSerp API без ключа та реєстрації.

## Мета

Допомогти користувачам знаходити нові AI-сервіси, шукати інструменти
за ключовими словами та фільтрувати їх за напрямом використання.

## Аудиторія

- розробники;
- дизайнери;
- маркетологи;
- автори контенту;
- користувачі, які шукають AI-інструменти.

## Сторінки

Проєкт використовує односторінкову структуру:

- головна сторінка з каталогом;
- пошук за назвою та описом;
- фільтрація за AI-категоріями;
- сортування за новизною або Domain Rating.

## Структура

- Header — назва проєкту та посилання на GitHub.
- Hero — опис проєкту та пошукове поле.
- Toolbar — категорії та сортування.
- Catalog — картки AI-сайтів.
- Footer — інформація про FreeSerp API.

## API

Використовується FreeSerp Main:

- endpoint: `https://freeserp.ai/api.php`;
- index: `sites`;
- тільки головні сторінки сайтів;
- фільтр AI-проєктів: `ai_startups=1`;
- API не потребує ключа або реєстрації.

## Запуск

```bash
pnpm install
pnpm dev

```

## Перевірка

```bash
pnpm build
pnpm lint
```

## Що не встигли

У рамках тестового завдання основний функціонал було реалізовано. Через обмежений час не додав окремі сторінки з детальною інформацією про кожен AI-сайт та повноцінну систему збереження обраних інструментів.

## Що можна покращити далі

У подальшому проєкт можна доповнити:

- сторінкою з детальною інформацією про обраний AI-сайт;
- обраним;
- пагінацією або нескінченним завантаженням;
- додатковими фільтрами;
- збереженням користувацьких фільтрів;
- більш детальною інформацією про кожен сервіс;
- автоматичним оновленням каталогу;
- окремим розділом з новими AI-сайтами.
